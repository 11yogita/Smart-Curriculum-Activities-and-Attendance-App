**AttendIQ – Smart Curriculum Activity & Attendance App**

AttendIQ is a smart web-based attendance management system that helps students track subject-wise attendance, predict leave impact on the 75% rule, and automate leave approvals—making academic planning easier for both students and teachers.
AttendIQ is designed to solve a very common problem faced by college students — maintaining the required **75% attendance** while managing leaves.

In most colleges, students don’t have a clear idea of how taking leave will affect their attendance percentage. This often leads to last-minute shortages and unnecessary stress. At the same time, teachers have to manually review and approve leave requests without any predictive insights.

AttendIQ simplifies this entire process by providing:
* Real-time attendance tracking
* Smart leave prediction
* Automated approval workflows

This makes attendance management **transparent, efficient, and data-driven**.

## 🎯 Key Features
### 👩‍🎓 For Students
* Subject-wise attendance tracking in real-time
* Attendance status indicators:

  * ✅ Safe
  * ⚠️ Shortage
  * 🚨 Critical
* Predict how planned leave will affect attendance
* Apply for leave directly through the system

### 👨‍🏫 For Teachers
* Centralized dashboard for all students
* Easy review of leave requests
* Visibility into attendance patterns
* Reduced manual workload

### ⚙️ Smart System Features
* Automated leave approval (based on 75% rule)
* Rule-based workflow:

  * Auto-approve (if attendance remains safe)
  * Manual review (if borderline)
* Real-time updates in dashboards
* Data visualization using charts and heatmaps
